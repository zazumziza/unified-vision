# Domain Model

Primary canonical objects in this foundation:
Person/Profile, ArtistIdentity, Genre, Scene, Work, Recording, Release, Track, MediaAsset, Event, Venue, Relationship/Follow, SupportSignal, Referral, Membership, Payment, LedgerEntry, Allocation, Claim, Source, Mention, Observation and AuditEvent.

Identity, role, ownership, evidence and account access remain conceptually separate.
